SHIP MANAGEMENT (18.1.81)
Open beneath Optimize & Export in the Corvette Save Manager, in the sidebar or I/O menu. This opens a separate resizable window and changes a save draft, not Blender scene objects. Save Changes reviews the destination and writes both save points from the latest source snapshot, creating verified backups. Close/Escape confirms before discarding unsaved changes. If the native window X closes with a draft, Cancel on the recovery prompt reopens it.

Ownership notice: existing missing, duplicate or unrecognized Corvette links no longer block opening Ship Management. Link Status explains each affected Main/Expedition context. Inventory, cargo, technology, class, saved stats and existing hyperslots remain editable. Move Up/Down and Add Minimal Corvette are locked only in affected contexts; Duplicate Save / Clear Builds still requires valid links in every context. Saving compares the draft with the source snapshot and preserves all uncertain ownership and build records exactly. No automatic link repair is attempted.

Ships: choose Main or Expedition, select a ship, and move it up/down. Ownership, Corvette build links, ship appearance and active-slot references move together. Add Minimal Corvette only accepts an empty slot. Its starter build can then be replaced using Export to Save. Ship Class offers C/B/A/S and preserves existing rolled base stats.

Inventory: drag to move or swap items. Technology uses 18 shared game icons; cargo uses text. Cargo has two six-row pages selected by the page button or mouse wheel. Search Add Item by localized English name or ID. Right-click chargeable technology to edit charge, or applicable upgrades to change their procedural # roll. Existing rolls for the same upgrade in this save can be reused. The game calculates final rolled values. Individual products such as Orbital Uplink occupy one slot each; larger quantities are distributed into free unlocked cells or rejected when space is insufficient. Unknown existing items remain intact. Unlock All expands technology to 60 and cargo to 120 cells.

Hyperslots: purple SC cells with a double outline and purple item text. Right-click an existing cell, choose Move Hyperslot, then click an unlocked destination. Escape cancels the move. No hyperslot creation or deletion is offered. Existing counts above four are preserved with an instability warning. Linked technologies use game LinkColour on orthogonal, same-family neighbors; upgrade accents use UpgradeColour.

Ship stats: the panel displays saved base rolls. Technology output and weapon DPS are calculated in game; no estimated auto-layout or DPS projection is offered.

Duplicate Save: open directly beneath Backup Saves in the Save Manager. Choose an empty game save slot and a new name. Default keeps one usable normal ship per populated context and clears built structures. Select extra ships/builds to retain. Keeping a Corvette also keeps its base record. Inventory, progression and customization are preserved. Source save is unchanged. Uses saved data, excluding pending Ship Management edits. Steam compressed saves and metadata are written together; other save platforms are not supported by this write path.

Backups: every save export or edit captures both save points and available metadata before writing. The gear beside Select Save sets the backup folder and number of generations retained per account/save slot. An empty folder uses nms_base_builder_backup beside each account. Older backups made by previous versions are kept.

Optimizer: add, remove, rename or reorder categories and add/remove/reorder part IDs. Earlier entries are serialized first; unlisted objects keep their relative order at the end. Removing a priority entry does not delete build objects. Functional part order can affect game selection/handling, including cockpit roles; no universal maximum-stat guarantee is made. Exact duplicate removal compares the complete saved object record, including orientation, scale and other fields.

Provenance: optimizer and management logic independently implemented. No TazMD code/templates used. Tiny technology icons and item metadata were extracted from installed No Man's Sky game data (Hello Games). Steam metadata codec adapted from libNOM.io, Copyright Christian Engelhardt 2021, GPL-3.0-only, https://github.com/zencq/libNOM.io; see licenses/libNOM.io-GPL-3.0.txt. In-game validation of new save editing features remains necessary.
