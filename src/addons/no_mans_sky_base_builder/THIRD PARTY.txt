Copyright and license notices are included in the wheel's dist-info directory.

PySide6 Essentials and Shiboken6 6.11.1
https://pypi.org/project/PySide6-Essentials/6.11.1/
https://pypi.org/project/shiboken6/6.11.1/
https://code.qt.io/cgit/pyside/pyside-setup.git/?h=6.11.1
https://download.qt.io/official_releases/QtForPython/pyside6/PySide6-6.11.1-src/
Qt/PySide license texts and third-party notices remain in the supplied wheels.
The DLLs are dynamically loaded from Blender's extension dependency directory;
they are not built into the extension's Python code.

Blender handles wheel installation using the extension manifest:
https://docs.blender.org/manual/en/dev/advanced/extensions/python_wheels.html

The PySide wheel is repacked with build tag 1. Four unused QML compile-time .obj
files were omitted because their paths exceed the normal Windows install limit.
Runtime DLLs, Python modules, resources and license files are unchanged.

BBE scene preview (18.1.6)
The previous Charon Forge lighting integration from private previews 18.1.0-18.1.5
has been retired. Its original GPL notices are preserved with archived copies.
The current stages.py implementation and static star background were authored
for BBE and do not use Charon Forge lighting code, sky tables or nebula textures.
Existing DjMonkey and Kuma credits for the rest of Base Builder remain applicable.

Display scenery and class-marker resources
Native pad meshes, marker geometry and texture masks originate from No Man's Sky,
Hello Games. Blender presentation shaders and bounded particle representations
are BBE approximations; these are not the game's renderer or particle simulation.
Game assets remain subject to their original rights, not the code's GPL license.
Build tooling: MBINCompiler, HGPAKTool and NMSDK were used to read installed game
assets. Those tools are not bundled in the extension.
